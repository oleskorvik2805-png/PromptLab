# PromptLab — готовый проект по промпт-инжинирингу

Ниже — объединённый и готовый вариант проекта в одном документе: цели, план обучения, шаблоны и практический кейс.

---

## 1) Цель проекта

Собрать практичную систему работы с промптами, чтобы:
- быстро получать качественные ответы от ИИ,
- воспроизводить результаты,
- измерять качество итераций,
- формировать портфолио прикладных кейсов.

## 2) Результаты, которые должны быть на выходе

- Библиотека шаблонов промптов под разные задачи.
- Минимум 4 прикладных кейса с измеримым результатом.
- Понятный процесс: гипотеза → промпт → результат → оценка → улучшение.
- Конвенция версионирования промптов (например, `task-name_v1`, `v2`, `v3`).

---

## 3) Roadmap на 4 недели

### Неделя 1 — База
- Роль и задача.
- Контекст и допущения.
- Формат ответа (JSON/Markdown/таблица).
- Ограничения и критерии успеха.

**Итог недели:** 5 рабочих базовых шаблонов.

### Неделя 2 — Качество и контроль
- Few-shot примеры.
- Декомпозиция задачи на шаги.
- Самопроверка по чек-листу.
- Уточняющие вопросы перед финальным ответом.

**Итог недели:** 3 сценария с сравнением версий и метрикой качества.

### Неделя 3 — Прикладные кейсы
- Редактура текста.
- Анализ требований.
- Генерация идей и планов.
- Суммаризация документов.

**Итог недели:** портфолио из 4 кейсов.

### Неделя 4 — Система
- Каталог промптов по категориям.
- Правила именования и версионирования.
- Ретроспектива по лучшим практикам.
- Подготовка итоговой демонстрации.

**Итог недели:** оформленный репозиторий + демонстрационный набор.

## 4) Готовые шаблоны промптов

### 4.1 Универсальный
```text
Ты — [роль].
Контекст: [краткий контекст задачи].
Цель: [ожидаемый результат].
Ограничения:
1) [ограничение 1]
2) [ограничение 2]
Формат ответа: [структура/формат].
Критерии качества:
- [критерий 1]
- [критерий 2]
Если данных недостаточно — задай до 3 уточняющих вопросов.
```

### 4.2 Для анализа
```text
Выступи как аналитик.
Проанализируй [объект анализа] с учетом [контекст].
Дай результат в формате:
- Ключевые наблюдения (3–5)
- Риски
- Рекомендации
- Следующие шаги на 7 дней
```

### 4.3 Для генерации плана
```text
Составь пошаговый план для [цель] на [срок].
Условия: [ресурсы/ограничения].
Вывод:
1. Этап
2. Действия
3. Результат этапа
4. Метрика завершения
```

### 4.4 Для улучшения текста
```text
Отредактируй текст для аудитории [аудитория].
Сохрани смысл, улучши структуру и ясность.
Верни:
1) Улучшенную версию
2) Что было изменено (bullet list)
3) 2 альтернативных заголовка
```

## 5) Практический кейс (готов к запуску)

**Ситуация:**
- Клиент: онлайн-школа английского.
- Задача: увеличить конверсию лендинга.
- Ограничение: ограниченный бюджет на редизайн.

**Промпт-задача:**
Сгенерировать 5 быстрых гипотез, которые можно проверить за 2 недели.

**Ожидаемый формат ответа:**
- 5 гипотез,
- для каждой: ожидаемый эффект, сложность, приоритет,
- общий порядок внедрения.

---

## 6) Как использовать этот проект

1. Выбери кейс/задачу.
2. Возьми шаблон из раздела 4.
3. Заполни роль, контекст, ограничения, критерии.
4. Проведи 2–3 итерации промпта (меняя по одному параметру).
5. Зафиксируй лучшую версию и выводы.
