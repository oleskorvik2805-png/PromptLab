# Шаблоны промптов

## 1) Универсальный шаблон

```text
Ты — [роль].
Контекст: [краткий контекст задачи].
Цель: [ожидаемый результат].
Ограничения:
1) [ограничение 1]
2) [ограничение 2]
Формат ответа: [структура/формат].
Критерии качества:
- [критерий 1]
- [критерий 2]
Если данных недостаточно — задай до 3 уточняющих вопросов.
```

## 2) Шаблон для анализа

```text
Выступи как аналитик.
Проанализируй [объект анализа] с учетом [контекст].
Дай результат в формате:
- Ключевые наблюдения (3–5)
- Риски
- Рекомендации
- Следующие шаги на 7 дней
```

## 3) Шаблон для генерации плана

```text
Составь пошаговый план для [цель] на [срок].
Условия: [ресурсы/ограничения].
Вывод:
1. Этап
2. Действия
3. Результат этапа
4. Метрика завершения
```

## 4) Шаблон для улучшения текста

```text
Отредактируй текст для аудитории [аудитория].
Сохрани смысл, улучши структуру и ясность.
Верни:
1) Улучшенную версию
2) Что было изменено (bullet list)
3) 2 альтернативных заголовка
```
