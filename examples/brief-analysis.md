# Пример кейса: анализ брифа

## Вход
Клиент: онлайн-школа английского.
Задача: увеличить конверсию лендинга.
Ограничение: бюджет на редизайн ограничен.

## Цель
Получить список быстрых гипотез, которые можно проверить за 2 недели.

## Ожидаемый формат ответа
- 5 гипотез
- для каждой: ожидаемый эффект, сложность, приоритет
- общий порядок внедрения
